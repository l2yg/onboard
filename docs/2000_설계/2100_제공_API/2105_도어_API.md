# 도어 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Door 메서드 15개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 도어 잠금과 위치, 글러브박스 잠금을 별도로 다룬다. 잠금 설정의 `true`는 잠금, `false`는 해제다.
- `setDoorPosition`의 완전 열림 값은 차종별로 다르다. `checkDoorPositionCapabilities`의 영역별 `AreaBounds<Int>`에서 범위를 확인하며 고정 백분율·고정 각도로 해석하지 않는다. 소스는 닫힘 최솟값이 보통 0이라고 설명한다.
- 도어 API의 영역은 `DoorArea`다. 제어 성공 콜백이 실제 문 동작 완료·안전 확인까지 보장하지는 않는다.

## 메서드 정의

도어 위치(열림 정도), 도어 잠금, 글로브박스 잠금을 조회·제어하고 변경 알림을 받는다. 각 기능의 지원 여부를 확인한다.

## 미정 사항과 확인 필요 사항

실제 계정 승인, 차종별 지원 영역·허용 값·주행 중 제한과 실차 동작은 미검증이다. 공개 문서·배포 선언에서 확인하지 못한 입력 의미·기본값·동작 보장은 추정하지 않는다. SDK 선택과 구체적인 제품 기능은 미정이며 개요 문서의 제공 상태·제약을 함께 확인한다.
