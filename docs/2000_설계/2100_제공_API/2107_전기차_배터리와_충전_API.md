# 전기차 배터리와 충전 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 EvBattery 메서드 30개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 배터리 SOC는 `Int?` 백분율, 충전 목표 한도는 `Float` 백분율, 전류 제한은 A다. EV 전비는 km/kWh이며 순간·마지막 충전 이후·누적·현재 주행을 구분한다.
- `setEvChargePercentLimit`는 0~100 범위 안에서도 차량이 지원하는 값만 사용한다. `checkEvChargePercentLimitCapabilities`가 반환하는 허용 목록을 확인한다.
- `setEvChargeSwitch(true/false)`는 충전 시작/중지 요청이다. 충전구 열림 요청과 별개이며 성공 콜백만으로 실제 충전 전력·충전 완료를 보장하지 않는다.
- 충전구/충전 스위치 설정의 KDoc에는 성공 인자를 Float로 표기한 부분이 있지만 실제 선언과 구현은 `Boolean?`이다. 문서의 함수 서명을 따른다.
- `getInstantaneousEvEfficiency`는 현재 폐기 어노테이션은 없지만 KDoc에 향후 폐기 계획이 있다. 기존 표의 '소스 선언 확인'은 영구 지원 보장이 아니다.

## 메서드 정의

배터리 충전량(SOC), 충전 스위치 상태, 충전 전류 제한, 현재·누적·순간·충전 이후 전비 조회. 전비와 SOC 변경 알림. 충전 전류 제한·목표 충전 비율·충전구 열림·충전 스위치 설정. 각 항목 지원 여부 확인.
