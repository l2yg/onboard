# 창문과 스마트글라스 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Window 메서드 29개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 창문 잠금·위치, 블라인드 이동, 스마트글라스 전역 상태·영역별 단계·패널별 명령은 별도 기능이다. 정수 위치/단계의 단위를 백분율로 고정하지 않는다.
- `getSmartGlassConfig`와 `setSmartGlassZoneState`의 `WindowArea`에는 정확히 한 영역만 넣는다.
- 패널 명령은 패널 순서대로 전달하고 구성의 `zoneCount`만큼 준비한다. 빈 목록은 로컬에서 거부된다. SDK가 길이를 구성과 자동 대조하거나 capability를 선조회하지 않으므로 앱이 확인해야 한다.
- `SKIP`은 해당 패널에 명령을 내리지 않음을 뜻하며 목록에서 제거하지 않는다. 전부 SKIP인 목록도 서비스로 제출된다.
- `setSmartGlassZoneState`의 성공 콜백은 제출한 명령을 되돌려 준다. 결과 패널 상태가 아니다.
- 구성은 `[zoneCount, levelCount]` 두 정수에서 해석한다. 구성이 있어도 단계 제어 지원이 보장되지 않으므로 `checkSmartGlassLevelCapabilities`를 따로 확인한다.
- `moveWindowBlind`는 이동 명령이고 `getCurrentWindowBlindPosition`은 위치값이다. 명령 접수와 최종 도달 위치를 구분한다.

## 미정 사항과 확인 필요 사항

실제 계정 승인, 차종별 지원 영역·허용 값·주행 중 제한과 실차 동작은 미검증이다. 공개 문서·배포 선언에서 확인하지 못한 입력 의미·기본값·동작 보장은 추정하지 않는다. SDK 선택과 구체적인 제품 기능은 미정이며 개요 문서의 제공 상태·제약을 함께 확인한다.
