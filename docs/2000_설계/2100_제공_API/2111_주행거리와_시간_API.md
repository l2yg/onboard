# 주행거리와 시간 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Odometer 메서드 35개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 누적 주행계는 km, 트립 거리는 m, 트립 주행시간은 분이다. 같은 `DistanceDrivenListener`여도 등록한 메서드에 따라 단위가 다르다.
- 현재 주행·누적·마지막 주유 이후 통계를 구분한다. 순간 트립 거리 계열과 잔여 주행거리 설정은 폐기 어노테이션이 있다.
- `setRangeRemainingDistance`는 m 단위의 추정 잔여 거리 설정이며 차량의 실제 배터리 용량이나 측정 주행거리를 바꾸는 기능으로 해석하지 않는다.

## 메서드 정의

총 누적계(Float?, km), 현재·누적·주유 이후 트립 거리(Float?, m)와 시간(Int?, 분) 조회·구독. 순간 트립 거리와 잔여 주행거리 설정(m)은 폐기 예정.
