# 안전과 경고 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Safety 메서드 37개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 오일/브레이크액 수준은 `OilLevelState`로 받는다. Boolean 경고와 수치 잔량으로 임의 치환하지 않는다.
- 워셔액 경고의 true는 부족 문제, 에어백 전개 true는 전개됨, 안전벨트 경고 true는 미착용이다. 일반적인 'true=정상' 규칙을 적용하지 않는다.
- `hasSeatAirbagEnabled`는 함수명과 KDoc의 true 의미가 충돌한다. 구현은 `SEAT_AIRBAG_ENABLED`의 Boolean을 전달할 뿐 의미 충돌을 해소하지 못하므로 운영사 확인 전 정상/고장으로 확정하지 않는다.
- 출력 저하 경고는 소스에서 엔진 문제로 설명하지만 모든 동력계의 구체적인 원인·진단 코드를 제공하는 API로 확대 해석하지 않는다.
