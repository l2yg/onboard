# 시트 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Seat 메서드 97개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 점유·벨트 체결, 시트/헤드레스트/요추/벨트 위치, 이동 명령, 메모리 선택, 열선·통풍 단계를 구분한다.
- `moveXxx`의 `MoveControl`은 BACKWARD/STOP/FORWARD 명령이며 목표 위치 `Int`나 물리 각도 입력이 아니다. 성공 시 전달되는 명령도 실제 최종 위치 측정값과 다르다.
- 위치 `Int`의 물리 단위와 범위, 열선·통풍 단계의 범위는 임의로 mm·도·섭씨로 정하지 않는다. capability 응답을 확인한다.
- `setHvacSeatTemperature`는 온도 단계값이며 HVAC 실내 설정 온도와 다르다.
- `selectSeatMemory`는 메모리 번호를 선택하고 실패 콜백만 가진다. 함수 반환을 선택 위치 도달 확인으로 취급하지 않는다.
- `getCurrentSeatHeadrestAnglePosition`의 KDoc에는 이동 콜백 설명이 섞여 있지만 실제 선언은 위치 `Int?` 조회다.

## 메서드 정의

착석 여부·안전벨트 체결, 시트 앞뒤/높이/깊이/기울기/등받이 각도, 벨트 높이, 헤드레스트 각도·앞뒤·높이, 허리받침 앞뒤·측면 지지 위치 조회/변경 알림. 각 축 이동, 시트 메모리 선택, 좌석 온도·통풍 조회·설정·변경 알림 및 지원 여부 확인. 메모리 저장 API는 현재 목록에서 확인하지 못했다.
