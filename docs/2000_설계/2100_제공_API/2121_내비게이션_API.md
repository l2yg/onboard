# 내비게이션 API

## 문서 정보

- 상태: 초안.
- 적용 범위: NaviHelper SDK의 NaviHelper 메서드 21개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- `NaviHelper(context)`를 생성하고 초기화 후 리스너를 등록한다. 콜백형 `initialize`는 최초 서비스 연결 성공과 초기 재시도 소진 실패를 알린다.
- 경로 요청·취소·경유지 추가/제거·옵션 변경·재탐색은 NAVI_ROUTE_SEARCH, 정보 조회와 `requestTrip`은 NAVI_ROUTE, 화면 요청은 NAVI_CUSTOM_MAP을 사용한다. 권한 미승인은 동기 `SecurityException` 경로가 있다.
- 요청 메서드의 `Unit` 반환은 경로 계산·안내 시작 완료 응답이 아니다. 결과는 `NaviHelperEventListener`에 전달되며 실제 이벤트는 내비 앱의 NaviProvider 구현에 의존한다.
- `getWaypointInfo` 등은 현재 정보를 요청하고 변경 이벤트와는 별개다. 응답 상관 ID·콜백 순서·시간 제한·스레드가 모든 메서드에 공통 보장된다고 가정하지 않는다.
- `removeWaypoint`는 임의 정수가 아닌 FIRST/SECOND/ALL의 `WaypointIndex`를 사용한다.
- `TripInfo.distance`는 m, `eta`는 초, `estimatedSocAtDest`는 %, `energyConsumption`은 Wh다. 예측 정보이며 실측 도착값이 아니다.
- `release()`는 서비스 연결과 등록 리스너를 해제한다. 공개 메서드에 없는 지도 영상 임베딩이나 내부 시스템 앱 API 사용 권한을 NAVI_CUSTOM_MAP만으로 가정하지 않는다.

## 미정 사항과 확인 필요 사항

실제 계정 승인, 차종별 지원 영역·허용 값·주행 중 제한과 실차 동작은 미검증이다. 공개 문서·배포 선언에서 확인하지 못한 입력 의미·기본값·동작 보장은 추정하지 않는다. SDK 선택과 구체적인 제품 기능은 미정이며 개요 문서의 제공 상태·제약을 함께 확인한다.
