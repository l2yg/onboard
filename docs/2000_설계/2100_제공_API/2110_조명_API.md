# 조명 API

## 문서 정보

- 상태: 초안.
- 적용 범위: Vehicle SDK의 Light 메서드 71개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- `LightSwitch`는 스위치 설정, `LightState`는 현재 조명 상태다. 스위치값과 실제 점등 상태를 구분한다.
- 독서등·앰비언트 조명은 좌석 영역을 사용하고 다른 조명은 각 선언의 전역/영역 조건을 따른다.
- 앰비언트 색상은 32비트 ARGB `Int`이며 소스 계약상 alpha는 0xFF다. 밝기와 색상은 별도 값이며 밝기를 0~100으로 임의 고정하지 않는다.
- `getHighBeamLightSwitch`, `getFrontFogLightSwitch`, `getRearFogLightSwitch`의 KDoc 일부는 LightState로 설명하지만 실제 선언·구현은 `LightSwitch?`다. 반환 서명을 우선한다.

## 메서드 정의

앰비언트 상태·스위치·밝기·색상 및 주행모드 연동 색상, 실내등, 독서등, 전/후방 안개등, 상향등, 하향등, 미등의 상태·스위치 조회. 각 조명 스위치와 앰비언트 밝기·색상·주행모드 연동 설정. 상태 변경 알림 및 지원 여부 확인.
