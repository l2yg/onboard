# 음성 출력 API

## 문서 정보

- 상태: 초안.
- 적용 범위: TextToSpeech SDK의 TextToSpeech 메서드 11개 이름과 해당 오버로드.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

이 영역의 공개 기능과 입력·콜백 출력·권한·폐기 여부를 확인한다. 다른 영역과의 공통 정책은 상위 문서에서 관리한다. 연결·조회·제어·리스너를 포함하며 SDK 내부 구현과 자동 생성 보일러플레이트는 제외한다.

## 동작 의미와 제한

- 가이드의 3.3.1 기준으로 생성자의 기본 모드는 HYBRID다. SERVER는 네트워크 실패 시 오류를 내며 자동 오프라인 전환하지 않는다. ON_DEVICE만 사용하면 서버 앱 등록이 필요 없다.
- 초기화 결과가 필요하면 `OnInitializeListener`를 사용한다. SERVER/HYBRID의 서버 합성은 일반 `registerApp(clientID, clientSecret, listener)`의 `onConnected()` 이후 요청한다.
- `setLocale`는 다음 합성 요청에 적용된다. 미설정 시 같은 앱의 이전 설정, 없으면 시스템 Locale을 사용한다. 지원 언어는 ko-KR/en-US/fr-CA/es-US/es-MX다.
- `speak(text, isFinal)`은 마지막 조각만 true로 보내며 기본값은 true다. `stop()`은 합성과 재생을 중지하고 `onStop()`으로 중지를 확인한다.
- 이벤트의 `onReady/onStart/onDone`는 각각 요청 준비/재생 시작/정상 재생 종료다. SDK 초기화 성공·서버 연결 성공과 혼동하지 않는다.
- `setAudioAttributes`, `setAudioZoneId`, `setSpeakerType`의 공개 참조 본문은 비어 있다. AAR 바이트코드에서 앞의 두 설정이 엔진 객체의 속성으로 저장되고 화자 설정은 비동기 엔진 경로로 전달되는 것을 확인했다. 허용값·기본값·재생 중 변경 반영 시점·차종 지원은 여전히 미확인이다.
- 추가 `registerApp` 두 오버로드는 바이트코드의 입력 이름이 각각 `(uaAppId, uaAppKey, uaAppName, onSuccess, onFail)`과 `(uaAppCode, onSuccess, onFail)`이며 UA 경로를 활성화한다. 일반 Client ID/Secret 경로와 구분한다. 이용 자격·발급 절차·서버 동작은 확인되지 않았다.
- 공개 진입점의 각 void 메서드는 서비스 권한을 먼저 검사하며 미승인 시 동기 `SecurityException`을 던지는 바이트코드를 확인했다. 오류 리스너만으로 권한 실패 전체를 처리할 수 없다.
- 같은 이벤트 리스너 인스턴스를 제거한 뒤 `release()`한다. 해제 후 재사용은 새 객체 생성·초기화 절차를 따른다.
- 오류는 초기화·서버 연결·재생 리스너에서 `ErrorType`으로 받는다. 권한/인증/네트워크/미지원 모드/언어/엔진 오류를 구분하고 알 수 없는 오류의 기본 분기를 둔다.

근거: [초기화·해제](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/initialization-and-release), [소개·모드](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/intro), [앱 등록](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/app-registration), [언어](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/set-locale), [합성·중지](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/start-and-stop), [이벤트](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/event-listeners), [오류](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/error-code).

## 미정 사항과 확인 필요 사항

실제 계정 승인, 차종별 지원 영역·허용 값·주행 중 제한과 실차 동작은 미검증이다. 공개 문서·배포 선언에서 확인하지 못한 입력 의미·기본값·동작 보장은 추정하지 않는다. SDK 선택과 구체적인 제품 기능은 미정이며 개요 문서의 제공 상태·제약을 함께 확인한다.
