# API 연동 참조

## 문서 정보

- 상태: 초안.
- 적용 범위: 공모전 제공 SDK 5종과 별도 Gleo 연동의 기획·개발 가능 범위 조사.
- 근거: 2026-10-27 조사한 공식 API 문서·릴리스 노트·배포 선언. 개별 출처는 본문에 명시한다.
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009. 제공 기능의 조사이며 제품의 채택·구현 완료를 뜻하지 않는다.

## 목적과 범위

공개 메서드명 530개·호출 선언 578개와 보조 타입 180개를 주제별 문서로 관리한다. 소스 범위·미확인 부분·계정 승인·실차 검증을 구분하며 모든 API를 프로젝트 요구사항으로 채택하지 않는다.

## 범위와 근거

- Vehicle 2.3.2, NaviHelper 3.0.5, TextToSpeech 3.3.1, SpeechToText 3.3.1, FusedLocation 1.1.3.
- 공개 진입점·차량 도메인 목록의 메서드명 530개와 해당 오버로드를 포함한다. 사용자 기능이 530개라는 뜻은 아니다. 리스너·데이터·enum은 별도 부록이다.
- 사이트맵의 공개 참조 경로와 배포 선언을 대조했다. 사이트맵의 모든 페이지를 각각 열어 의미를 검증했다는 뜻은 아니다. 본문이 빈 참조 페이지는 배포 자료로 보완했다.
- Vehicle/NaviHelper/FusedLocation 및 navi-data 3.0.4의 공식 소스 JAR을 읽었다. TTS/STT 동일 버전 소스·Javadoc은 404여서 AAR의 JVM 공개 선언·바이트코드를 확인했다. 이후 배포 바이너리의 순수 모델 계약 46건을 JVM에서 실행했다. 차량·위치·음성 서비스는 호출하지 않았다.
- Kotlin 서명은 입력 이름·타입·콜백 출력·반환형을 담는다. JVM ABI만으로 파라미터명·Kotlin nullability·기본 인자를 추정하지 않는다. 추가로 바이트코드·가이드에서 확인한 이름과 동작은 상세 문서에 구분해 적는다. 생성자·자동 생성 copy/component/equals/hashCode 및 내부 구현은 기능 API 수에 포함하지 않았다.
- 일부 보조 모델의 계산 속성·기본값·생성자 상세는 아래 자동 추출에 없을 수 있다. 원본과 타입 참조를 함께 확인한다.
- 메서드 수와 선언의 보존 확인은 API 의미 전체의 검증을 뜻하지 않는다. 이 문서군은 공개 선언의 참조 목록이며 모든 메서드의 KDoc 계약·모델 속성 의미까지 검증한 완전한 SDK 명세로 취급하지 않는다. 직접 재확인한 세부 계약은 해당 영역 문서에 명시한다.
- SDK 5종의 수명주기·입력 의미·단위·권한·콜백·오류와 남은 불확실성의 검토 범위는 [SDK 동작 계약 검토](2002_SDK_동작_계약_검토.md)를 따른다. 정적 계약 확인과 실제 서비스 실행 검증은 구분한다.

[대회 개발 환경](https://appdevchallenge.auto-hmg.io/guide/development), [SDK 개요](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/), [릴리스 노트](https://document.pleos.ai/docs/pleos-only/release-note/sdk-261015).

## 제공 상태와 사용 권한

기획 단계의 사용 가능 범위와 승인 제약은 [제공 API 요약](../1000_요구사항_분석/1003_제공_API.md)에서 관리한다. 아래 계약과 상세 선언은 실제 계정 승인·차종별 지원 여부를 전제로 참조한다.

## 데이터 해석과 폐기 상태

- getLowTirePressure는 저압 임계값(Float?, kPa)이다. 현재 공기압·경고 Boolean이 아니다.
- getCurrentSteeringWheelAngle은 앞바퀴 조향각(도, 왼쪽 음수)이다. 핸들 자체 회전각이 아니다.
- CRN은 Connected Resource Name이다. CRN 조회·capability는 폐기 예정이며 VIN 전환 권장. 에뮬레이터 2.1.0부터 CRN 제공 종료.
- Fuel SinceCharge는 이름과 달리 소스상 마지막 주유 이후 연비다. 연비는 L/100 km, 전비는 km/kWh.
- 주행계는 km, 트립 거리는 m, 트립 시간은 분이다. 내비의 시간·ETA는 초다.
- setRangeRemainingDistance(m)와 순간 트립 거리 계열은 폐기 예정이다.
- hasSeatAirbagEnabled는 함수명과 KDoc의 true 의미 설명이 불일치한다. 정상/이상 의미를 확정하지 않는다.
- LLM SDK는 제공 종료. Gleo Interface는 별도 앱 함수 호출 연동이다.

## 공통 호출 계약

같은 이름이라도 오버로드별 폐기 여부·콜백 계약이 다르다. 함수 이름 전체를 폐기된 것으로 오해하지 않는다.

Vehicle: initialize 후 getXxx로 도메인을 얻는다. get/check/set의 결과는 onComplete에 전달되며 실패는 Exception이다. ?는 null 가능성을 뜻한다. 각 set 성공 콜백은 실제 선언을 따른다. 소스상 VehicleException에는 errorCode가 있지만, 확인한 Vehicle 2.3.2 AAR에는 원래 클래스명이 없어 직접 import·캐스팅하는 코드를 권장하지 않는다. 배포물 불일치의 근거와 재현은 [SDK 검증 결과](../4000_테스트/4001_SDK_검증_결과.md)를 따른다.

CapabilityConfig.accessType은 NONE/READ/WRITE/READ_WRITE다. 지원 영역·허용 목록·최소최대는 capability의 별도 콜백 데이터에서 얻는다. AreaBounds는 minValue/maxValue, 온도 설정은 HvacTemperatureConfigArray의 범위·증가 간격을 확인한다. MoveControl은 BACKWARD/STOP/FORWARD다.

대표 조회 권한은 CAR_DOORS/CAR_WINDOWS/CAR_CLIMATE/CAR_DRIVE/CAR_ENERGY/CAR_INFO/CAR_LIGHTS/CAR_MIRRORS/CAR_SAFETY/CAR_SEATS/CAR_TOLL이며 제어는 CONTROL_CAR_* 계열이다. 함수별 어노테이션을 우선한다. NaviHelper는 NAVI_ROUTE·NAVI_ROUTE_SEARCH·NAVI_CUSTOM_MAP을 구분한다. TTS_SERVICE·STT_SERVICE는 음성 권한이다. FUSED_LOCATION은 dangerous 권한이다.

[Vehicle 권한](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle-permission), [내비 권한](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/declaring-permissions), [위치 권한](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/FusedLocation/declaring-permissions).

## 음성·위치·내비의 추가 계약

- 음성 모드: SERVER는 서버 전용, ON_DEVICE는 차량 내 처리, HYBRID는 서버 우선·네트워크 실패 시 온디바이스 전환이다. 서버 사용은 Client ID·Secret과 등록 성공이 필요하다.
- TTS speak(text, isFinal=true)는 완성 발화다. 분할 텍스트는 마지막 조각만 true로 전달한다. 화자 문자열·오디오 구역의 구체 허용 값은 미확인이다.
- TTS 지원 Locale: ko-KR/en-US/fr-CA/es-US/es-MX. STT의 Locale 지원과 자동 동일시하지 않는다.
- STT 가이드도 별도로 확인한 결과 동일한 Locale 목록을 명시한다. 두 SDK 모두 미설정 시 같은 앱의 이전 설정, 없으면 시스템 Locale을 사용하며 설정은 다음 요청에 적용된다.
- STT request는 차량 마이크 인식, sendAudio(ByteArray)/completeAudioSend는 ON_DEVICE PCM 입력이다. 인식 텍스트가 곧 명령 실행은 아니다.
- 두 음성 SDK는 초기화 결과 리스너와 version 속성을 지원한다. 추가 registerApp 오버로드는 바이트코드에서 UA 입력 이름·경로까지 확인했지만 이용 자격·서버 인증 계약은 미확인이다. 공개 27개 void 진입점 모두 서비스 권한을 동기 검사한다.
- TTS getAmbientAi, STT getAmbientAi/getCallApi와 관련 확장 타입은 일반 공개 참조 목록에 없으므로 일반 제공 기능으로 분류하지 않았다.
- getLastKnownLocation은 마지막 계산 위치이며 null일 수 있다. isSupported는 서비스 패키지 존재 여부이고 기능 전체의 동작 보장이 아니다.
- ProximityAlertRequest는 위도 -90~90, 경도 -180~180, 유한한 양수 반경(m), 비어 있지 않은 ENTER/EXIT 집합이 필요하다. 등록 후 alertId로 제거한다.
- LocationData는 latitude/longitude/altitude/heading/confidence/timestampMillis를 갖는다. confidence 단위와 세부 의미는 소스에 없어 미확인이다.
- Navi RouteInfo는 latitude/longitude·POI·주소·경로 옵션으로 경로를 요청한다. TripInfo는 거리(m)·ETA(초)·도착 SOC(%)·소비전력량(Wh)·교통 및 경로 요약을 제공한다.
- NavigationScreenRequest는 전경, 즐겨찾기, 집/직장 등록, 주변 충전소, 설정, 현재 위치, 전체 경로, 장소 검색, POI 상세, 최근 목적지, 경로 옵션, 경로 편집 화면 요청을 구분한다.
- 내비 이벤트 전달은 Navigation 앱 구현·상태에 따라 달라질 수 있다.

[합성](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/start-and-stop), [앱 등록](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/app-registration), [TTS 언어](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/TextToSpeech/set-locale), [PCM 입력](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/SpeechToText/sending-audio-data).

## Gleo Interface

App Schema: packageName/appDescription/version/actionCalls. Function: component/name/description/parameters/required. actionCalls는 최대 3개이며 description은 영어, 함수명은 대문자·밑줄 형식이다. 파라미터 타입은 string/number/boolean/array, enum은 문자열만 지원한다. activity는 startActivity, service는 sendBroadcast 경로다. Callback Schema로 결과를 반환한다. 실제 Schema 전달·등록 조건은 별도 확인한다.

[개념](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/core-concepts), [앱 스키마](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/app-capability), [콜백](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/action_callback), [전달](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/deliver-schema).

## 실행 확인 범위

실제 계정 승인, 에뮬레이터·실차 구동, 차종별 capability와 주행 중 제한, 서버 응답은 검증하지 않았다. Google Fused Location의 배경 위치 정책을 Pleos의 보장으로 해석하지 않는다. 공개 데이터 모델이 존재해도 그 필드가 모든 환경에서 채워짐을 보장하지 않는다.

## 미정 사항과 확인 필요 사항

실제 계정 승인, 차종별 지원 영역·허용 값·주행 중 제한과 실차 동작은 미검증이다. 공개 문서·배포 선언에서 확인하지 못한 입력 의미·기본값·동작 보장은 추정하지 않는다. SDK 선택과 구체적인 제품 기능은 미정이며 개요 문서의 제공 상태·제약을 함께 확인한다.
