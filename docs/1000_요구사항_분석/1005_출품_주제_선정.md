# 출품 주제 선정

**출품 주제는 ‘태그 없는 분실물의 역추적’으로 정한다.**

차로 여러 곳을 다녀온 뒤 물건이 없어진 경우, 마지막으로 본 기억과 차량 출입·정차 이력을 대조해 어디부터 다시 확인할지 정하는 Pleos Connect 앱이다.

현재는 주제 선정만 확정하며, 상세 기획과 기술 검증은 별도로 진행한다.

관련 조사: [공모전 아이디어 검토](1004_공모전_아이디어_검토.md).
