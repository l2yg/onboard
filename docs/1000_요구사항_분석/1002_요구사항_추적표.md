# 요구사항 추적표

## 문서 정보

- 상태: 초안.
- 적용 범위: 대회 조건과 확정된 제품 기능을 등록한다.
- 근거: 2026-10-27 사용자 요청과 대회 내용 문서의 공식 출처.
- 관련 요구사항: REQ-CONTEST-001~010.

## 목적과 범위

요구사항의 원본을 유지하면서 준비·설계·구현·검증 위치와 실제 상태를 연결한다. 조건의 상세 내용과 완료 기준은 원본에서 관리한다. 설계·구현이 필요 없는 행정 항목은 해당 없음으로 구분한다.

## 미정 사항과 확인 필요 사항

- REQ-VISIT-ADDRESS-001 수정 전 검증: Geocoder 미지원·경로 생성 실패는 [수정 전 기록](../4000_테스트/4002_앱_구현_검증.md#2026-10-30-최신-자동-검증과-실제-연결-시험)에 보존한다. 수정 후 Pleos 대체 주소와 한국 경로 생성은 위 추적표의 최신 검증을 따른다.

- REQ-VISIT-ADDRESS-001의 2026-10-30 최신 범위: 길 안내는 목록에서 제공하고 상세의 중복 버튼은 제거, 상세 버튼 간격 16dp 적용, 좌표 미저장 사유 표시, 연습용 가상 주소와 실제 경로 요청을 하지 않는 안내 설명. 최신 간격 변경은 빌드·앱 갱신 후에도 실제 화면 확인을 구분한다.

- 실제 참가 준비 상태와 제품 기획·설계·구현·검증 자료가 생기면 해당 행만 갱신한다.
- 위 미제출·미구현 등의 상태는 저장소와 이 대화에서 확인 가능한 범위다. 외부에서 수행한 작업이 있으면 근거를 받아 갱신한다.
- 아직 없는 문서에 링크를 만들거나 원본 확인만으로 제출·구현·검증 완료를 표시하지 않는다.
