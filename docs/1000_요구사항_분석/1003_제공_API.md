# 제공 API

## 문서 정보

- 상태: 초안.
- 적용 범위: 공모전 SDK를 활용하는 제품 기획의 가능 범위와 제약.
- 근거: 2026-10-27 조사한 [대회 개발 환경](https://appdevchallenge.auto-hmg.io/guide/development), [SDK 개요](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/), [프로젝트·SDK 신청](https://document.pleos.ai/docs/pleos-only/create-my-project).
- 관련 요구사항: REQ-CONTEST-001, REQ-CONTEST-009.

## 목적과 범위

제품 기획 시 활용 가능한 외부 기능과 확인해야 할 제약을 정리한다. 제공 기능을 제품 요구사항으로 일괄 채택하지 않는다. 메서드·입출력 타입·콜백·권한 선언과 데이터 해석의 상세 원본은 [API 연동 참조](../2000_설계/2001_API_연동_참조.md)에서 관리한다.

## 기획에 활용할 기능 범위

| 제공 수단 | 활용 가능한 기능 범위 |
| --- | --- |
| Vehicle | 차량 정보·상태 조회, 변경 감지, 지원되는 차량 기능 제어 |
| NaviHelper | 목적지·경로 요청, 경로·주행 정보와 내비 화면 연동 |
| TextToSpeech | 텍스트 음성 출력 |
| SpeechToText | 차량 마이크 또는 지원되는 오디오 입력의 텍스트 변환 |
| FusedLocation | 위치 조회·변경 감지·근접 영역 알림 |
| Gleo Interface | 앱이 공개한 기능을 음성 도우미에서 호출하는 별도 연동 |

음성 인식 결과가 곧 명령 실행은 아니다. LLM SDK는 제공 종료이며 Gleo 연동과 구분한다. 각 기능의 실제 사용 가능 여부는 아래 제약을 따른다.

## 제공 상태와 제약

- 공식 SDK 신청 안내에는 Vehicle State·NaviHelper는 별도 신청 없이 사용 가능, Vehicle Control·위치·음성은 준비 중으로 기재돼 있다. 대회 안내는 SDK 5종을 소개하므로 실제 Workspace와 운영사무국 확인 전까지 전부 즉시 사용 가능하다고 가정하지 않는다.
- Vehicle 권한은 협의·승인 범위에서 사용한다. 차종별 지원 기능과 허용 범위가 다르며 API 선언의 존재가 실차 지원을 보장하지 않는다.
- 실제 계정 승인, 에뮬레이터·실차 구동, 주행 중 제한, 서버 응답은 미검증이다.
- 위치·차량·음성 데이터의 제공 여부와 값은 환경에 따라 달라질 수 있다. 필요한 데이터가 제공되지 않는 경우의 제품 동작은 기능 채택 후 정한다.
- 사용자·역할, 정상·예외 흐름, 입력·출력, 우선순위와 비기능 기준은 제품 기능이 아직 선정되지 않아 미정이다. SDK 목록 자체가 제품 기능 요구사항은 아니다.

## 채택 시 확인할 조건

제품 기능을 정할 때 필요한 SDK·데이터·권한을 연결하고, 승인 여부·차종 지원·실행 환경을 확인한다. 해당 기능의 완료 조건에는 정상 응답뿐 아니라 미지원·권한 거부·데이터 없음·오류 시의 동작도 포함한다. 현재 SDK 선택·제품별 완료 조건과 구현·검증은 미정이다.

## 미정 사항과 확인 필요 사항

- 제품 기능과 사용할 SDK, 대상 사용자·차종·실행 환경.
- Workspace에서 실제 제공되는 SDK와 권한 승인·신청 조건.
- 데이터 미제공·미지원·네트워크 오류·주행 중 제한에 대한 제품 정책.
- 기능별 구현 방식과 검증 방법. 상세 API 조사가 실제 실행 검증을 의미하지 않는다.
