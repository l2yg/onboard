# onboard

Pleos Connect용 분실물 역추적 앱입니다. 마지막 기억과 차량의 정차·문 상태 기록을 대조해 다시 확인할 곳을 정리합니다. 물건 자체의 위치를 감지하거나 분실 장소를 확정하지 않습니다.

- [개발 환경](docs/3000_구현/3001_개발_환경.md): 도구 버전·Pleos 에뮬레이터 준비·실행 방법.
- [프로젝트 문서](docs/index.md): 공모전 조건과 SDK 조사.

Android Studio에서 저장소 루트를 열고 기존 Pleos AVD를 실행한 다음 `app`을 실행합니다. 새 AVD를 설치할 필요는 없습니다.

1. `차량 상태 권한 허용`으로 정차 확인에 필요한 속도 권한을 허용합니다.
2. 기어 P·정차가 확인되면 `기록 시작`을 눌러 차량·위치 기록에 동의합니다.
3. 정차 후 `물건 찾기 시작`에서 물건과 마지막 기억을 입력합니다.
4. 방문별 문 기록을 비교하고 확인 결과·찾음·미발견 종료를 저장합니다.

`모의 기록으로 사용해 보기`는 실제 기록과 분리된 예시 세 곳으로 탐색 흐름을 체험합니다. 시연 모드로 전환하면 실제 기록을 중지합니다. 실제 수집은 위치 공급자·권한·차량별 API 지원이 필요하며 앱 강제 종료·차량 전원 종료 중 수집을 보장하지 않습니다.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

- 설치용 개발 APK: `app/build/outputs/apk/debug/app-debug.apk`.
- 릴리스 빌드: `:app:assembleRelease`, 산출물은 `app/build/outputs/apk/release/app-release-unsigned.apk`. 배포 서명은 별도 준비가 필요합니다.
- 데이터는 앱 전용 SQLite에 저장하며 서버 전송·클라우드 백업을 사용하지 않습니다. 원시 기록·방문은 기록 시작 시 7일 이전 자료를 정리하고 탐색 메모·결과는 전체 삭제 전까지 보관합니다.
- 실제 구현·검증 범위와 남은 항목은 [구현 계획](docs/3000_구현/3002_분실물_역추적_구현_계획.md)을 따릅니다.
