# 차량 발자취

Pleos Connect용 차량 방문 이력 복기 앱입니다. 날짜별 정차 기록을 보고 특정 방문부터 시간순으로 돌아보며 방문별 메모를 남깁니다. 실제 수집한 이동 위치와 내비 알림을 참고할 수 있으며, 기록하지 못한 경로를 복원하지 않습니다.

반복 차량 상태는 관측 구간·횟수로 묶고 위치는 이동·시간 변화에 따라 선별 저장합니다. 중간 위치는 일부 생략됩니다. 설정에서 수신 건수와 저장 행 수를 확인할 수 있습니다. 큰 글자·넓은 버튼을 기본으로 제공하며 오늘·어제를 바로 선택할 수 있습니다. 제출용 설명과 조건부 저장량 비교는 출품 주제 문서에서 관리합니다.

- [개발 환경](docs/3000_구현/3001_개발_환경.md): 도구 버전·Pleos 에뮬레이터 준비·실행 방법.
- [프로젝트 문서](docs/index.md): 공모전 조건과 SDK 조사.
- [제출용 릴리스 APK](apk/l2yg_차량발자취_release.apk): 버전 0.1.0, 전용 키로 서명된 설치 파일.
- [시연 영상 · 무음](videos/시연_소리없음.mp4): 앱 실행 흐름 녹화.

테스트 환경은 Pleos Connect v2.1.0 x86_64 에뮬레이터(Android 14 / API 34)입니다. Vehicle SDK 2.3.2와 NaviHelper 3.0.5를 사용하며 실차는 별도 검증하지 않았습니다. 차량 속도·위치 권한이 필요하고, 기록 시작 시 위치 및 알림 권한을 안내합니다. 실제 주소·내비 기능은 제공자 연결 및 차량 지원 상태에 영향을 받습니다.

APK를 Pleos 기기에 설치한 후 앱 목록에서 `차량 발자취`를 엽니다. 기존 개발 APK와 서명이 다르면 바로 덮어쓸 수 없으며, 앱 삭제 시 로컬 기록도 삭제되므로 필요한 기록을 먼저 보관해야 합니다.

Android Studio에서 저장소 루트를 열고 기존 Pleos AVD를 실행한 다음 `app`을 실행합니다. 새 AVD를 설치할 필요는 없습니다.

1. `차량 상태 권한 허용`으로 정차 확인에 필요한 속도 권한을 허용합니다.
2. 기어 P·정차가 확인되면 `기록 시작`을 눌러 차량·위치 기록에 동의합니다.
3. 정차 후 `방문 기록`에서 날짜를 선택하거나 `여기부터 돌아보기`로 방문을 시간순으로 확인합니다.
4. `방문 보기`에서 상세·이동 위치를 확인하고 방문에 메모를 남깁니다. `내 메모`에서 수정·삭제할 수 있습니다.

`기록 설정 → 모의 기록으로 사용해 보기`는 실제 기록과 분리된 예시 세 곳으로 방문 복기 흐름을 체험합니다. 모의 기록으로 전환하면 실제 기록을 중지합니다. 예시 주소는 가상 주소이며 실제 길 안내를 요청하지 않습니다. 촬영 전용 시연 모드는 제거했습니다. 실제 수집은 위치 공급자·권한·차량별 API 지원이 필요하며 앱 강제 종료·차량 전원 종료 중 수집을 보장하지 않습니다.

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

- 설치용 개발 APK: `app/build/outputs/apk/debug/app-debug.apk`.
- 제출용 파일은 `apk/l2yg_차량발자취_release.apk`입니다. Android Studio의 `Generate Signed App Bundle / APK`에서 release를 선택해 서명했습니다. `:app:assembleRelease`만 실행하면 별도 서명 설정이 없어 unsigned APK가 생성됩니다. 서명키와 비밀번호는 저장소에 포함하지 않습니다.
- 데이터는 앱 전용 SQLite에 저장하며 자체 서버·클라우드 백업을 사용하지 않습니다. 주소는 Android 시스템 Geocoder 또는 기록 좌표와 100m 이내인 Pleos 내비 위치 주소로 확인하며 제공자와의 통신이 발생할 수 있습니다. 원시 기록·방문은 기록 시작 시 7일 이전 자료를 정리하고 메모는 직접 삭제 전까지 보관합니다.
- 실제 구현·검증 범위와 남은 항목은 [구현 계획](docs/3000_구현/3002_분실물_역추적_구현_계획.md)을 따릅니다.
